# PE_App

UMC CUK 11th PE_App 미션 저장소입니다.

## 프로젝트 구조

```text
PE_App/
├── FE/  # Flutter 프론트엔드
└── BE/  # 백엔드
```

프론트엔드는 `FE/`, 백엔드는 `BE/`에서 각각 작업합니다. Git 브랜치 생성,
커밋, Push 등의 작업은 저장소 최상위 디렉터리를 기준으로 진행합니다.

## 프론트엔드 실행

```bash
cd FE
flutter pub get
flutter run
```

## 백엔드 실행

백엔드 프로젝트가 구성된 이후 `BE/`의 실행 안내를 따릅니다.
