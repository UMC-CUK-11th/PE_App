## MovieLog
UMC 11기 PE(Mobile) 파트 Flutter 워크북 미션 앱입니다.

| 주차 | 브랜치 | 내용 |
|---|---|---|
| 0주차 | `feature/week-0` | 초기 세팅 및 영화 기록 시작 화면 |
| 1주차 | `feature/week-1` | UI 기초와 Material 3 · 내 프로필 화면 |
| 2주차 | `week02` | 레이아웃과 사용자 입력 · 회원가입 Form |
| 3주차 | `week03` | 화면 전환과 사용자 인터랙션 · GoRouter |

## 실행
```bash
cd FE
flutter pub get
flutter run
```
